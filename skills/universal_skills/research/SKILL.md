# Research

## Purpose
Gather, evaluate, and synthesize reliable information needed to solve a task.

## When to use
Use when the task depends on external facts, unfamiliar technologies, specifications, current information, or uncertain technical details.

## Procedure
1. Define the exact question.
2. Prefer authoritative and primary sources.
3. Cross-check important claims.
4. Distinguish facts, assumptions, and conclusions.
5. Record relevant sources and limitations.
6. Apply only information relevant to the project.

## Rules
- Never fabricate sources, APIs, specifications, or facts.
- Prefer current documentation for software and APIs.
- Clearly indicate uncertainty.
- Do not research when existing project information is sufficient.
