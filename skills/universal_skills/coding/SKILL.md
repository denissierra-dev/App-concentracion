# Coding

## Purpose
Implement maintainable, correct, and project-consistent code.

## When to use
Use when creating or modifying source code.

## Procedure
1. Understand the existing code and architecture.
2. Identify interfaces, dependencies, and constraints.
3. Make the smallest coherent change.
4. Follow the project's established conventions.
5. Handle errors and edge cases.
6. Run or define appropriate verification.

## Rules
- Do not rewrite unrelated code.
- Do not invent unavailable dependencies or APIs.
- Preserve public interfaces unless a change is required.
- Prefer readable code over clever code.
- Keep security and performance implications in mind.
