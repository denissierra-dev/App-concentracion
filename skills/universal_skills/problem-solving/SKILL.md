# Problem Solving

## Purpose
Provide a disciplined general method for solving unfamiliar or complex problems.

## When to use
Use when the problem does not fit a more specialized skill or requires coordinating several skills.

## Procedure
1. Define the problem precisely.
2. Separate known facts from assumptions.
3. Identify constraints.
4. Decompose the problem.
5. Generate plausible approaches.
6. Compare approaches by correctness, complexity, cost, and risk.
7. Select an approach.
8. Execute incrementally.
9. Verify the result.
10. Learn from failures and update the approach.

## Rules
- Prefer evidence over intuition.
- Avoid unnecessary complexity.
- Make assumptions explicit.
- Re-evaluate the approach when new evidence contradicts it.
