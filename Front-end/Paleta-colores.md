# 🎨 Paletas de Colores para Web

Cada paleta incluye su **color complementario** como acento (regla 60-30-10) y dos variantes acromáticas (blanco dominante y negro dominante).

---

**Armonía:** Acromática (blanco dominante)

| Rol web | Color | HEX |
|---------|-------|-----|
| Fondo | Blanco puro | `#FFFFFF` |
| Superficie | Gris claro | `#D9D9D9` |
| Texto secundario | Gris medio | `#8A8A8A` |
| Texto principal | Grafito | `#333333` |
| Acento / CTA | Negro profundo | `#000000` |

> **Uso:** Minimalista editorial. Portfolios, blogs y marcas de lujo. Contraste AAA.

## 🧭 Principios aplicados

- **Regla 60-30-10:** 60% fondo, 30% primario/superficies, 10% complementario en CTA y enlaces.
- **Accesibilidad:** pares texto/fondo con contraste AA/AAA.
- **Dos acromáticas:** una con blanco dominante (light) y otra con negro dominante (dark mode).
- **Jerarquía por rol:** fondo → superficie → primario → texto → acento.
